# 功能需求文档 — 个人简历与作品集展示软件

## 项目概述

一个运行在 Windows 电脑上的单 HTML 文件应用，用于展示个人简历和作品集。双击 `index.html` 即可在浏览器中打开使用。内置编辑功能，无需接触代码即可管理内容。

## 用户角色

| 角色 | 说明 |
|------|------|
| 普通浏览者 | 查看简历和作品集内容，使用搜索功能 |
| 管理员（你） | 通过密码进入管理模式，增删改所有内容 |

---

## 功能清单

### F1. 首页 / 关于我（P0 必须有）

| ID | 功能 | 优先级 |
|----|------|--------|
| F1.1 | 展示个人照片（支持上传/更换） | P0 |
| F1.2 | 展示姓名和头衔/职业 | P0 |
| F1.3 | 展示个人简介（多行文字） | P0 |
| F1.4 | 展示个人爱好标签 | P0 |

### F2. 简历板块（P0 必须有）

| ID | 功能 | 优先级 |
|----|------|--------|
| F2.1 | 教育经历列表（学校、专业、学位、时间段） | P0 |
| F2.2 | 工作经历列表（公司、职位、职责描述、时间段） | P0 |
| F2.3 | 技能标签展示（技能名 + 熟练度） | P0 |

### F3. 作品集板块（P0 必须有）

| ID | 功能 | 优先级 |
|----|------|--------|
| F3.1 | 项目卡片网格布局展示 | P0 |
| F3.2 | 每个项目包含：名称、描述 | P0 |
| F3.3 | 每个项目支持多张图片展示 | P0 |
| F3.4 | 每个项目包含技术标签 | P0 |
| F3.5 | 每个项目包含外部链接 | P1 |
| F3.6 | 每个项目包含完成时间 | P1 |
| F3.7 | 点击项目卡片查看详情（弹窗） | P0 |
| F3.8 | 项目详情中图片轮播 | P1 |

### F4. 联系我板块（P0 必须有）

| ID | 功能 | 优先级 |
|----|------|--------|
| F4.1 | 展示邮箱 | P0 |
| F4.2 | 展示电话号码 | P1 |
| F4.3 | 展示社交账号链接 | P1 |

### F5. 搜索功能（P0 必须有）

| ID | 功能 | 优先级 |
|----|------|--------|
| F5.1 | 全局搜索框，位于页面顶部 | P0 |
| F5.2 | 实时过滤作品集项目（按名称、描述、技术标签） | P0 |
| F5.3 | 搜索结果高亮显示 | P2 |

### F6. 管理后台（P0 必须有）

| ID | 功能 | 优先级 |
|----|------|--------|
| F6.1 | 管理模式入口（简易密码保护） | P0 |
| F6.2 | 添加/编辑/删除个人基本信息 | P0 |
| F6.3 | 添加/编辑/删除教育经历 | P0 |
| F6.4 | 添加/编辑/删除工作经历 | P0 |
| F6.5 | 添加/编辑/删除技能标签 | P0 |
| F6.6 | 添加/编辑/删除项目 | P0 |
| F6.7 | 添加/编辑/删除联系信息 | P0 |
| F6.8 | 图片上传（自动压缩） | P0 |

### F7. 数据导入/导出（P1 应该有）

| ID | 功能 | 优先级 |
|----|------|--------|
| F7.1 | 一键导出所有数据为 JSON 备份文件 | P1 |
| F7.2 | 从 JSON 文件导入恢复数据 | P1 |

---

## 非功能需求

| ID | 需求 | 说明 |
|----|------|------|
| NF1 | 离线可用 | 不依赖任何外部网络资源，完全离线运行 |
| NF2 | 无需安装 | 双击 HTML 文件即可打开，无需安装任何软件 |
| NF3 | 响应式布局 | 在不同屏幕尺寸（台式机/笔记本/平板）上正常显示 |
| NF4 | 数据持久化 | 关闭浏览器后数据不丢失（使用 IndexedDB） |
| NF5 | 数据可备份 | 支持导出备份，换电脑可恢复 |
| NF6 | 浏览器兼容 | 支持 Chrome、Edge、Firefox 最新版本 |

---

## 验收标准

1. 双击 `index.html` 能在浏览器正常打开
2. 所有板块内容正确显示
3. 搜索框输入关键词能实时过滤项目
4. 管理模式下能成功增删改所有内容
5. 导出数据 → 清空数据 → 导入数据后内容完整恢复
6. 在不同窗口大小下布局正常，不错位
